### How to verify the binaries

`tools/fetch_binaries.sh` downloads the same versions from the official release pages. The downloaded files match the ones in `lib/` byte for byte.

### About the tunnel library

`libhev-socks5-tunnel.so` is taken from the ByeDPIAndroid v1.2.0 release (https://github.com/dovecoteescapee/ByeDPIAndroid). That build registers JNI methods for the class `io.github.dovecoteescapee.byedpi.core.TProxyService`, which is why `src/io/github/dovecoteescapee/byedpi/core/TProxyService.kt` uses that package name. No ByeDPIAndroid source code is included in this project, only the compiled library.

### Как проверить бинарники

`tools/fetch_binaries.sh` скачивает те же версии с официальных страниц релизов. Файлы совпадают с лежащими в `lib/` байт в байт.

### Про библиотеку туннеля

`libhev-socks5-tunnel.so` взята из релиза ByeDPIAndroid v1.2.0 (https://github.com/dovecoteescapee/ByeDPIAndroid). Эта сборка регистрирует JNI-методы для класса `io.github.dovecoteescapee.byedpi.core.TProxyService`, поэтому `src/io/github/dovecoteescapee/byedpi/core/TProxyService.kt` лежит в таком пакете. Кода ByeDPIAndroid в проекте нет, только эта скомпилированная библиотека.
